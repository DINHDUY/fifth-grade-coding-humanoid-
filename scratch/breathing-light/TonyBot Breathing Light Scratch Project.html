Breathing Light Scratch Project

A WonderCode/Scratch program that makes TonyBot's ultrasonic RGB LEDs smoothly brighten and dim like a breathing light, using the Tonybot Main Program, Repeat, and Glowy Ultrasonic Sensor blocks.

Events Control Variables Operators My Blocks Tonybot extension Glowy Ultrasonic Sensor

Colors follow the standard Scratch block language. Control and Variables use two different shades of orange — check the icon, not just the hue. The Tonybot and Glowy Ultrasonic Sensor extension colors are approximate; confirm against your installed WonderCode palette.

Goal

  1. Initialize TonyBot safely.
  2. Control the ultrasonic RGB LEDs.
  3. Gradually increase and decrease LED brightness.
  4. Optionally cycle through multiple colors.
  5. Turn the LEDs off when the program finishes.

Setup in WonderCode

  1. Open WonderCode.
  2. Add the extension: Robot → Tonybot.
  3. Add the Glowy Ultrasonic Sensor extension.
  4. Connect TonyBot over USB.
  5. Select the correct CH340 COM port.
  6. Use Upload Mode when transferring the program.
ℹ The ultrasonic sensor is pre-installed on TonyBot and communicates over I2C. The same extension controls its RGB lights.

Reusable Scratch blocks

Tonybot Initialize

Establishes a known robot posture before the light program starts.

🧩 define Tonybot Initialize
▶ run action group 0 1 time
⏱ wait 1 seconds
Set All LEDs (red) (green) (blue)

Uses the Glowy Ultrasonic Sensor color block to set both RGB lights. If the extension provides one block for all LEDs, use that block instead.

🧩 define Set All LEDs red green blue
💡 set left RGB to red green blue
💡 set right RGB to red green blue
Breathing Color (red) (green) (blue)

Creates a Scratch variable named brightness and uses it to scale the color. Start with 10 brightness steps; increase to 20 for a slower, smoother fade.

🧩 define Breathing Color red green blue
⚙ set brightness to 0
↻ repeat 10
🧩 Set All LEDs red × brightness ÷ 10 green × brightness ÷ 10 blue × brightness ÷ 10
⚙ change brightness by 1
⏱ wait 0.1 seconds
↻ repeat 10
🧩 Set All LEDs red × brightness ÷ 10 green × brightness ÷ 10 blue × brightness ÷ 10
⚙ change brightness by -1
⏱ wait 0.1 seconds
Lights Off

Call this block at the end of the program, or before disconnecting TonyBot.

🧩 define Lights Off
🧩 Set All LEDs 0 0 0

Main program — blue breathing light

🏁 when green flag clicked
🧩 Tonybot Initialize
⚙ set brightness to 0
↻ repeat 20
🧩 Breathing Color 0 0 255
🧩 Lights Off

The official example uses blue light and breathes approximately every two seconds. Use a dimly lit environment to see the effect clearly.

Optional multicolor version

🏁 when green flag clicked
🧩 Tonybot Initialize
⚙ set brightness to 0
∞ forever
🧩 Breathing Color 0 0 255
🧩 Breathing Color 0 255 0
🧩 Breathing Color 255 0 0

Cycles through blue, green, and red. Use the same RGB values for the left and right LEDs for a synchronized effect — or different values per side for a two-color look. A forever loop never reaches a stop block on its own, so pair it with a separate "when stop clicked → Lights Off" script during testing.

Tuning

Change one setting at a time:

  1. Increase the number of brightness steps for a smoother fade.
  2. Increase the wait time for a slower breathing rhythm.
  3. Change the RGB values to select another color.
  4. Use different left and right RGB values for a two-color effect.
  5. Increase the repeat count for a longer demonstration.

Upload and validation

  1. Save the Scratch project.
  2. Click Upload.
  3. Wait for the upload-success message.
  4. Test one color before enabling the multicolor loop.
  5. Confirm that the LEDs brighten and dim smoothly.
  6. Run Lights Off before disconnecting or powering down TonyBot.
