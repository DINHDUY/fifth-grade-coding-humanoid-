# Support

For questions about using TonyBot hardware, HiWonder Python Editor, WonderCode, firmware, or vendor software, consult the [official TonyBot documentation](https://docs.hiwonder.com/projects/Tonybot/en/latest/) first.

For issues specific to Mission Control:

1. Search existing GitHub issues.
2. Open a bug report with reproduction steps and environment details.
3. Remove student information, credentials, and device identifiers before sharing logs or screenshots.

Use the private process in `SECURITY.md` for security concerns.
