Walk-in-a-Circle Scratch Project

A WonderCode/Scratch program that makes TonyBot travel around a circular path using repeated forward and turning action groups — a polygon approximation of a circle, tunable by segment count and turn behavior.

Events Control Boolean operator Block parameter My Blocks Tonybot extension Glowy Ultrasonic Sensor

Block shapes and category colors follow the standard Scratch block language. Boolean reporters are hexagonal and slot into the diamond notch of an if block. Extension colors are approximate — confirm against your installed WonderCode palette.

Goal

  1. Initialize TonyBot safely.
  2. Repeat forward-and-turn segments to trace a circular path.
  3. Support tuning the effective radius via segment count and turn behavior.
  4. Complete one or more laps and return to a stable stop.
  5. Optionally show routine state with RGB LED feedback.

Action groups used

TonyBot runs these through runActionGroup(id, count).

IDMeaning
0Stand / stop
1Walk forward
3Turn left
4Turn right
⚠ Firmware-dependent: action-group behavior can vary by installed firmware. Test every group before building the final routine.

Setup in WonderCode

  1. Open WonderCode.
  2. Add the extension: Robot → Tonybot.
  3. Connect TonyBot over USB.
  4. Select the correct CH340 COM port.
  5. Use Upload Mode.
  6. Test all movement blocks on a clear, flat surface.

Circle Segment (direction)

One segment is a short forward movement followed by a small turn. Repeating segments produces a polygon that approximates a circle.

First prototype — 12-segment circle

🏁 when green flag clicked
🧩 Tonybot Initialize
↻ repeat 12
🧩 Circle Segment right
🧩 Safe Stop

Try 16 or 20 segments for a smoother path once the 12-segment version is stable.

Adjust the circle size

The radius depends on the ratio between forward movement and turning: more forward movements before each turn widens the radius; turning more frequently, or repeating the turn action group, tightens it. Reducing the turn repeat count widens it again.

Larger-radius segment
↻ repeat 2
🧩 Move Forward
🧩 Turn Right
Smaller-radius segment
🧩 Move Forward
🧩 Turn Right
🧩 Turn Right

Tune these variations carefully — action-group distance and turn angle both depend on the robot firmware.

Validation and safety

Test in this order:

  1. Test Tonybot Initialize.
  2. Test Move Forward once.
  3. Test Turn Right once.
  4. Test one circle segment.
  5. Test four segments.
  6. Test one complete 12-segment circle.
  7. Tune segment count, movement count, and timing.
  8. Test the left-turn version.
  9. Add multiple laps only after the single-lap version is stable.
Keep TonyBot away from walls, cables, stairs, and slippery surfaces. This routine creates a polygon approximation of a circle; exact circular motion requires tuning the action-group distances and turn angles for the specific TonyBot firmware.
