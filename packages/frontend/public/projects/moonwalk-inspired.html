Moonwalk-Inspired Scratch Routine

A short, safe, moonwalk-inspired dance built entirely from TonyBot's prebuilt action groups. No copyrighted music or choreography is reproduced — this is an original movement pattern assembled from the robot's own dance library.

Goal

  1. Initialize TonyBot in a stable standing pose.
  2. Play a short introduction.
  3. Perform a repeated backward-gliding dance pattern.
  4. Add a dance accent or turn.
  5. Stop and return to a stable standing pose.

Action groups used

TonyBot runs these through runActionGroup(id, count).

IDMeaning
0Stand / stop
1Walk forward
2Walk backward
3Turn left
4Turn right
9Wave
150–158Dance actions
⚠ Firmware-dependent: these mappings can vary by installed firmware. Test every group on the actual unit before locking it into the final routine.

Setup in WonderCode

  1. Open WonderCode on a Windows computer.
  2. Add the extension: Robot → Tonybot.
  3. Connect TonyBot over USB.
  4. Select the correct CH340 COM port.
  5. Do not use COM1 unless it is confirmed to be the robot controller.
  6. Use Upload Mode when transferring the program.

The Tonybot extension, CH340 port, and upload workflow are covered in section 5.1.2 of the imported Scratch documentation.

Reusable My Blocks

Events Control My Blocks Tonybot extension

Block shapes and category colors follow the standard Scratch block language (Control = orange, My Blocks = pink, extension blocks = their own color). The Tonybot extension's exact shade can vary by WonderCode version — confirm against your installed palette.

Tonybot Initialize

Establishes a known standing pose before every performance.

🧩 define Tonybot Initialize
▶ run action group 0 1 time
⏱ wait 1 seconds
Run Action Group (id) (repeat count)

Wraps the extension block for reuse. Use a repeat count of 1 during testing — avoid indefinite repeats.

🧩 define Run Action Group id repeat count
▶ run action group id repeat count
⌛ wait until action group finishes
Moonwalk Step

Conservative starting pattern. Tune the delays experimentally — if the backward action doesn't look right, test the dance groups instead of combining group 2 with group 0.

🧩 define Moonwalk Step
▶ run action group 2 1 time
⏱ wait 0.3 seconds
▶ run action group 0 1 time
⏱ wait 0.2 seconds
Moonwalk Accent

Test groups 150–158 individually and pick the best fit — don't assume any one group is "the moonwalk."

🧩 define Moonwalk Accent
▶ run action group 150 1 time
⏱ wait 0.2 seconds
Safe Stop

Keep this available as an emergency stop, and call it at the end of every routine.

🧩 define Safe Stop
▶ run action group 0 1 time
⏱ wait 1 seconds

If the backward step doesn't create a convincing glide, substitute one of the tested groups 151–158 as a complete prebuilt dance phrase instead.

Tuning sequence

Change only one variable at a time:

  1. Backward action-group repeat count
  2. Delay after the backward step
  3. Dance action-group selection
  4. Number of repetitions
  5. Turn timing
  6. Starting and ending posture

Use a flat, non-slippery surface and leave clear space around the robot.

Validation and safety

Test in this order:

  1. Run Tonybot Initialize only.
  2. Test action groups 150–158 one at a time.
  3. Test one Moonwalk Step.
  4. Run two steps.
  5. Run the complete routine at low repetition counts.
  6. Confirm that Safe Stop always returns TonyBot to a stable pose.
Before scaling up:
  • Do not use continuous loops until the robot consistently returns to a stable standing pose.
  • Avoid movement experiments near obstacles or while TonyBot is on an unstable or slippery surface.
