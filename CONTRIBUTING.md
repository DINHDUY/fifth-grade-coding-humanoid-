# Contributing to TonyBot Mission Control

Thank you for helping make robotics programming approachable for Grade 5 learners.

## Before you start

- Search existing issues before opening a new one.
- For substantial changes, open an issue first so the learning goal and scope can be discussed.
- Do not commit credentials, private student information, proprietary vendor files, or generated build output.
- Treat safety as a requirement: new movement examples must include safe testing guidance.

## Development

```bash
make install
make dev
make check
```

The frontend lives in `packages/frontend`. Keep curriculum content typed and reusable, prefer accessible semantic HTML, and keep robot behavior behind the adapter boundary. Add or update tests for changes to application logic.

## Pull requests

Pull requests should explain:

- What changed and which learner or teacher need it addresses.
- How the change was tested.
- Any safety, accessibility, content, or deployment considerations.
- Screenshots or a short recording for meaningful visual changes.

Keep pull requests focused. Maintainers may request revisions to improve clarity, safety, accessibility, or age appropriateness.

## Content and third-party materials

Only contribute content that you have the right to publish. HiWonder documentation, source material, trademarks, and downloaded artifacts may have terms separate from this repository’s MIT-licensed original code.
